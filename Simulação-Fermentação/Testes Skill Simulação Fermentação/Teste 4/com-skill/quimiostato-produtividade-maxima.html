Contínuo · varredura de D

O D de produtividade máxima

No fim você tem um programa que varre a taxa de diluição, acha o D de maior produtividade de etanol e mostra o precipício que existe logo depois dele.

O modelo

Dorna contínua de volume constante: entra mosto a Sin, sai caldo na mesma vazão. A taxa de diluição D = F/V (1/h) é o único botão, e em regime permanente as três derivadas são zero.

dXdt =(μ−D)⋅X dSdt =D⋅(Sin−S) −μ⋅XYx/s dPdt =Yp/x⋅μ⋅X −D⋅P , μ=μmax⋅SKs+S
  • (μ − D)·X — crescimento menos arraste. Zerá-lo com X > 0 exige μ = D: quem fixa a taxa específica de crescimento é a bomba, não a levedura.
  • D·(Sin − S) — o que entra de ART menos o que escapa sem reagir, em g·L⁻¹·h⁻¹.
  • −D·P — o etanol também é arrastado; é por isso que a produtividade é D·P, e não P.

Com μ = D, inverter Monod dá o estacionário inteiro, sem integrar nada:

S=Ks⋅Dμmax−D , X=Yx/s⋅(Sin−S) , P=Yp/x⋅X

O código

Os parâmetros e os dois D que importam

mu_max = 0.30    # 1/h
Ks     = 1.0     # g/L
Yxs    = 0.05    # gX/gART
Ypx    = 8.0     # gP/gX
Sin    = 100.0   # g/L
V      = 10.0    # m3

D_crit = mu_max * Sin / (Ks + Sin)                # 1/h  — washout
D_opt  = mu_max * (1 - np.sqrt(Ks / (Ks + Sin)))  # 1/h  — produtividade máxima

D_crit é μ avaliado no mosto de entrada: acima disso nem a célula em contato com Sin cresce rápido o bastante para se manter. D_opt sai de dPr/dD = 0 e tem raiz fechada — calcule-a antes da varredura para ter contra o que conferir o argmax.

O estacionário, resolvido na álgebra

def estacionario(D):
    """X, S, P, produtividade. Zero acima do washout."""
    if D <= 0 or D >= D_crit:
        return 0.0, Sin, 0.0, 0.0
    S = Ks * D / (mu_max - D)     # de mu = D, invertendo Monod
    X = Yxs * (Sin - S)
    P = Ypx * X
    return X, S, P, D * P

Não há solve_ivp aqui de propósito. Existindo solução fechada, integrar é mais lento e menos confiável — e o guarda em D >= D_crit não é decoração: sem ele, Ks·D/(mu_max − D) devolve S > Sin e X negativo, um estado sem sentido físico que o gráfico exibiria sem reclamar.

A varredura e o máximo

D  = np.linspace(1e-4, mu_max, 3000)          # 1/h
Pr = np.array([estacionario(d)[3] for d in D])  # g/L/h
i  = int(np.argmax(Pr))
print("varredura: D = %.4f, Pr = %.4f" % (D[i], Pr[i]))
print("formula  : D = %.4f, Pr = %.4f" % (D_opt, estacionario(D_opt)[3]))

Varrer até mu_max, e não até D_crit, é o que faz o washout aparecer dentro do gráfico em vez de ficar na borda. A malha precisa ser fina perto do pico: com 100 pontos o argmax erra o D na terceira casa, e é justamente ali que a curva decide entre 9,8 e 8,2 g·L⁻¹·h⁻¹.

A conferência por integração

def derivadas(t, y, D):
    X, S, P = y
    mu = mu_max * max(S, 0.0) / (Ks + max(S, 0.0))
    return [(mu - D) * X,
            D * (Sin - S) - mu * X / Yxs,
            -D * P + Ypx * mu * X]

def por_integracao(D, T=4000.0):
    s = solve_ivp(derivadas, [0, T], [1.0, 0.0, 0.0], args=(D,),
                  method="Radau", rtol=1e-10, atol=1e-12)
    X, S, P = s.y[:, -1]
    return X, S, P, D * P

A integração serve para confirmar a álgebra, não para descobrir o número. Radau porque perto do washout a biomassa e o substrato andam em escalas de tempo muito diferentes. E o resultado tem uma armadilha embutida: em D = 0,2970, a 10⁻⁴ do crítico, mesmo 4000 h não bastam — o integrador devolve Pr = 0,70 contra os 0,12 verdadeiros. Discordando os dois, o errado é a integração.

Dois painéis com sharex, e não um só: produtividade está em g·L⁻¹·h⁻¹ e as concentrações em g/L. Empilhá-las num eixo só daria um rótulo mentiroso — separadas, o D onde P começa a desabar fica alinhado verticalmente com o joelho da produtividade.

Ver o programa completo 
"""Quimiostato de etanol: qual D dá a maior produtividade.

Requer: numpy, scipy, matplotlib.
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

mu_max = 0.30    # 1/h
Ks     = 1.0     # g/L
Yxs    = 0.05    # gX/gART
Ypx    = 8.0     # gP/gX
Sin    = 100.0   # g/L
V      = 10.0    # m3

D_crit = mu_max * Sin / (Ks + Sin)                # 1/h
D_opt  = mu_max * (1 - np.sqrt(Ks / (Ks + Sin)))  # 1/h


def estacionario(D):
    """X, S, P, produtividade no estado estacionario. Zero acima do washout."""
    if D <= 0 or D >= D_crit:
        return 0.0, Sin, 0.0, 0.0
    S = Ks * D / (mu_max - D)          # de mu = D, invertendo Monod
    X = Yxs * (Sin - S)
    P = Ypx * X
    return X, S, P, D * P


D  = np.linspace(1e-4, mu_max, 3000)             # 1/h
Pr = np.array([estacionario(d)[3] for d in D])   # g/L/h
i  = int(np.argmax(Pr))
print("varredura : D = %.4f 1/h, Pr = %.4f g/L/h" % (D[i], Pr[i]))
print("formula   : D = %.4f 1/h, Pr = %.4f g/L/h" % (D_opt, estacionario(D_opt)[3]))
print("washout   : D_crit = %.4f 1/h  (F = %.3f m3/h)" % (D_crit, D_crit * V))

Xo, So, Po, Pro = estacionario(D_opt)
print("no otimo  : X=%.3f  S=%.3f  P=%.2f g/L  F=%.3f m3/h  %.1f kg etanol/h"
      % (Xo, So, Po, D_opt * V, Pro * V))


def derivadas(t, y, D):
    X, S, P = y
    mu = mu_max * max(S, 0.0) / (Ks + max(S, 0.0))
    return [(mu - D) * X,
            D * (Sin - S) - mu * X / Yxs,
            -D * P + Ypx * mu * X]


def por_integracao(D, T=4000.0):
    s = solve_ivp(derivadas, [0, T], [1.0, 0.0, 0.0], args=(D,),
                  method="Radau", rtol=1e-10, atol=1e-12)
    X, S, P = s.y[:, -1]
    return X, S, P, D * P


print("\n   D      Pr analitico   Pr integrado")
for d in (0.10, D_opt, 0.29, 0.2970, 0.31):
    print("%.4f      %8.4f       %8.4f" % (d, estacionario(d)[3], por_integracao(d)[3]))

fig, (a1, a2) = plt.subplots(2, 1, sharex=True, figsize=(7, 6))
a1.plot(D, Pr)
a1.axvline(D_opt, color="k", lw=1)
a1.axvline(D_crit, color="k", lw=1, ls=":")
a1.set_ylabel("Produtividade (g/L/h)")
E = np.array([estacionario(d)[:3] for d in D])
a2.plot(D, E[:, 0], label="X (g/L)")
a2.plot(D, E[:, 1], "--", label="S (g/L)")
a2.plot(D, E[:, 2], ":", label="P (g/L)")
a2.axvline(D_crit, color="k", lw=1, ls=":")
a2.set_xlabel("Taxa de diluição D (1/h)")
a2.set_ylabel("Concentração (g/L)")
a2.legend()
plt.tight_layout()
plt.savefig("quimiostato.png", dpi=140)
Ver a resposta

D ótimo = 0,2701 h⁻¹, o que significa F = 2,701 m³/h na dorna de 10 m³. Ali o estacionário é X = 4,548 g/L, S = 9,050 g/L, P = 36,38 g/L, e a produtividade máxima é 9,828 g·L⁻¹·h⁻¹ — 98,3 kg de etanol por hora no volume inteiro.

Passando disso: o washout está em Dcrit = 0,2970 h⁻¹ (F = 2,970 m³/h), só 10% acima. A queda começa antes dele: em D = 0,29 a produtividade já caiu para 8,236, e em D = 0,295 para 4,838. Cruzado o crítico, X → 0, S → 100 g/L e a dorna passa a devolver mosto: a levedura é arrastada mais rápido do que consegue crescer. Não há recuperação por si — é preciso baixar D e reinocular.

Os valores acima vêm da solução fechada e foram conferidos por integração (Radau, rtol 10⁻¹⁰) em D = 0,10 · 0,2701 · 0,29 · 0,31, com coincidência em todas as casas impressas. A exceção é D = 0,2970, discutida no passo da conferência.

O que a curva diz

  • A produtividade sobe quase reta até 0,25 h⁻¹ porque P mal se move nesse trecho — em D = 0,10 o etanol é 39,8 g/L e em D = 0,2701 ainda é 36,38. Quem cresce é o multiplicador D. O pico em 0,2701 é onde a perda de P finalmente supera o ganho de vazão.
  • O ótimo está a 91% do washout: entre operar no máximo e perder a dorna há 0,027 h⁻¹, ou 0,27 m³/h de vazão. Errar a bomba 10% para cima não custa 10% da produção — custa toda ela.
  • Produtividade máxima não é conversão máxima. Em D = 0,2701 sobram S = 9,05 g/L, ou 9% do ART indo embora sem fermentar; em D = 0,10 sobram 0,5 g/L (99,5% convertido), mas a produtividade cai a 3,98 g·L⁻¹·h⁻¹, 40% do máximo. Qual dos dois vale mais depende do preço do mosto contra o do tanque.
  • Arraste Ks de 1,0 até 10 g/L e veja o pico recuar para 0,2095 h⁻¹ enquanto o washout só desce para 0,2727: o ótimo cai de 91% para 77% do crítico, e a operação ganha margem. Afinidade alta pelo açúcar (Ks baixo) rende mais, e aproxima o ponto de operação do precipício.
