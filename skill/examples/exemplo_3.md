# Exemplo 3 — Produção de Etanol

## Entrada (enunciado)
"Simule a produção de etanol em fermentação com levedura, considerando consumo de glicose e formação de etanol. Explique os resultados para um aluno iniciante."

## Saída esperada (resumo)
- Modelo com biomassa, substrato (glicose) e etanol.
- Relações de rendimento para conversão substrato → biomassa/produto.
- Código Python executável com gráficos.
- Interpretação dos perfis e implicações no processo.
