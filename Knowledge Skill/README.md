# Knowledge Skill

Base de conhecimento para a skill de fermentação. A estrutura segue a pasta `skill`, com foco em conceitos, equações, estudos de caso, referências e modelos de documentação.

## Estrutura
- `concepts/`: fundamentos de cinética e bioprocessos
- `equations/`: balanços de massa e modelos
- `glossary/`: termos técnicos
- `case_studies/`: aplicações de fermentação
- `references/`: bibliografia inicial
- `templates/`: modelos reutilizáveis

Use este conteúdo como referência técnica inicial; valide parâmetros e condições operacionais com fontes específicas para cada processo.
